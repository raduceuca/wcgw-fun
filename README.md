# wcgw.fun

Source of [wcgw.fun](https://wcgw.fun), the site of WCGW. What could go wrong? Tools for the aftermath. Someone has to.

WCGW is Radu Ceucă's studio: fractional design leadership and product design for teams that need a senior designer who ships, plus small sharp tools built for the AI aftermath.

## What is in here

`site/` is the whole website: one `index.html`, one `styles.css`, the logo, favicon and OG image. Static, no build step, no framework. Open the HTML file or put the folder behind any web server.

`wcgw-fun-brief.md` is the brief the site was built from. `CLAUDE.md` and `docs/plans/` are the notes the agents work from; they are committed on purpose, the site was built with them.

## Brand in one paragraph

Kode Mono. Phosphor green on near-black, or dark ink on off-white. A dome with rings and a plus and an x for eyes. A morse line at the bottom for people who read those.

## Not a template

The copy, the mark and the name are WCGW's. Fork the mechanics if you like; leave the brand.
